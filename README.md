# Personal Portfolio Website

A modern personal portfolio website built to present my professional background, technical skills, selected projects, and experience as a Full-Stack Engineer.

The website provides visitors with a clear overview of my work and offers a direct way to explore my projects and get in touch with me.

## Key Features

- 👤 **About Section**  
  Introduces my professional background, technical interests, and experience.

- 🛠️ **Skills and Technologies**  
  Presents my main technical skills and development tools.

- 💼 **Experience Section**  
  Highlights my professional roles, responsibilities, and practical experience.

- 🚀 **Projects Showcase**  
  Displays selected projects with descriptions, technologies, screenshots, and links.

- ✉️ **Contact Form**  
  Allows visitors, recruiters, and collaborators to contact me directly.

- 📱 **Responsive Design**  
  Provides a consistent experience across desktop, tablet, and mobile devices.

- ⚡ **Performance and Accessibility**  
  Designed with attention to fast loading, readable content, keyboard access, and a smooth user experience.

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- React
- JavaScript

## My Contribution

I designed and developed the website structure, responsive interface, project showcase, contact functionality, and reusable frontend components.

## Project Purpose

The portfolio serves as a professional online presence where companies, universities, recruiters, and collaborators can learn about my experience and review my technical work.
