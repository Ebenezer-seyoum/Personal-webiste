# Personal Portfolio Website
This is my personal portfolio website, built using Next.js, TypeScript, and Tailwind CSS. It showcases my projects, skills, experience, and contact information in a modern, responsive design. The website is optimized for performance, accessibility, and smooth user experience.

🚀 Features
👤 About Me Section: Professional bio, skills, and experience highlights.
✉️ Contact Form: Functional contact form for direct communication.
📱 Responsive Design: Works seamlessly on desktop, tablet, and mobile devices.
